Ovládání

Výběr

Levé tlačítko / tažení rámečku · Shift = přidat · dvojklik nebo Ctrl+klik = všechny stejného typu na obrazovce · Tab = přepnout podskupinu · Ctrl+1–9 uložit skupinu, 1–9 vybrat (2× = kamera) · F1 = celá armáda · . = nečinný dělník · Backspace = radnice

Rozkazy

Pravé tlačítko = chytrý rozkaz (jdi / útoč / těž / stav / oprav) · Shift = zařadit do fronty · A + klik = útočný pochod · P + klik = hlídkovat · S = stop · H = držet pozici · M = přesun · skupina se pohybuje ve formaci

Dělník

G = těžit hlavní surovinu · F = těžit dřevo / houbu · B = nabídka staveb (H radnice, E dům, B kasárna, S stáje, W dílna, D přístav, T věž, L hradba) · R = opravit · Hradba: klik na začátek a konec, Shift = pokračovat

Budova

Q W E R T Z = výcvik · U = vylepšit (tier) · I / O = výzkum útoku / pancíře · Y = shromaždiště (na důl/les = dělníci rovnou těží) · X = zrušit poslední položku fronty · Delete = zbourat (2× pro důležité budovy) · G = brána / zazdít u hradby

Kamera a ostatní

Šipky, okraj obrazovky, střední tlačítko = posun · kolečko = zoom · minimapa: levé = kamera, pravé = rozkaz, Alt+klik = označit spoluhráčům · Space = poslední útok / označení · Enter = chat · Alt = zobrazit životy · Esc = zrušit / menu

Cíl

Znič všechny nepřátelské budovy (kromě hradeb). Radnice úrovně 4 odemkne hrdinu. Vylepšuj věže, budovy a výzkumy, stav domy pro populaci.
